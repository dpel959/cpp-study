# 경로 탐색 벤치마크 결과

## 측정 목적

8방향 이동에서 BFS, 다익스트라, Closed List를 사용하는 A*, Closed List 없이 `best` 비용으로 오래된 후보를 거르는 A*를 같은 미로에서 비교했습니다.

다익스트라를 가중치 최단 경로의 기준으로 사용하고, 두 A*의 최종 경로 비용이 다익스트라와 같은지도 매 미로마다 검증했습니다.

## 측정 조건

- 빌드: Visual Studio 2022, MSVC v143, Release x64, C++17
- 이동: 상하좌우 비용 10, 대각선 비용 14
- 휴리스틱: Octile Distance
- 미로 크기: 25×25, 51×51, 99×99
- 반복: 크기별 300개, 총 900개의 미로
- 난수: 기준 시드 `20260907`부터 순차 적용
- 측정 범위: 각 알고리즘의 탐색 자료구조 생성, 경로 탐색과 경로 복원

`expanded_nodes`, `enqueued_nodes`, `max_open_size`는 실행 환경에 흔들리지 않는 알고리즘 동작 지표입니다. 실행 시간은 운영체제 스케줄링과 캐시 상태의 영향을 받으므로 같은 컴퓨터에서도 달라질 수 있습니다.

## 해석

A* (Closed)는 다익스트라와 비교해 평균 확장 노드를 다음과 같이 줄였습니다.

- 25×25: 약 51.0% 감소
- 51×51: 약 56.7% 감소
- 99×99: 약 59.3% 감소

미로가 커질수록 목적지 방향을 고려하는 Octile 휴리스틱이 탐색 범위를 더 크게 줄였습니다. 두 A*는 총 900개 미로에서 다익스트라와 같은 경로 비용을 찾아 최단 비용 검증을 모두 통과했습니다.

Closed A*와 No-Closed A*의 확장 노드 수는 이번 입력에서 같았습니다. 현재 휴리스틱이 이동 비용과 일관되고, `best`에 기록된 비용보다 나쁜 후보를 건너뛰기 때문입니다. No-Closed 방식은 별도의 `closed` 2차원 배열을 사용하지 않지만, 다른 그래프나 일관되지 않은 휴리스틱에서도 같은 결과가 나온다고 일반화할 수는 없습니다.

A*는 전체 확장 노드는 줄였지만 순간적으로 보관한 최대 후보 수는 더 컸습니다. 즉, 목적지에 필요한 영역을 집중적으로 탐색하는 대신 우선순위 큐에 더 많은 경계 후보가 동시에 남는 공간-시간 트레이드오프가 나타났습니다.

BFS와 다익스트라의 경로 비용이 같은 이유는 현재 Binary Tree 방식으로 만든 미로가 두 지점 사이에 사실상 하나의 경로를 만드는 구조이기 때문입니다. 가중치가 있는 일반 그래프에서 BFS가 최소 비용을 보장한다는 뜻은 아닙니다.
